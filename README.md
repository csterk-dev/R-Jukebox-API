# RpiWebMusicPlayerAPI

## 📕 About

This repository contains the Websocket server and youtube API integration for the **R Jukebox** (*formally the RaspberryPi Web Music Player*) app.

---
## 🚀 Running

* Use `yarn build` to to compile the Typescript code to the `build/` directory. 
* Use `yarn start` to start the Node.js server.
* Use `yarn dev` to simultaneously build and start the the Node.js server.
