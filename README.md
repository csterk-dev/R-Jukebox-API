# RpiWebMusicPlayerAPI

## 📕 About

Built using Socket.IO and Express.js, this repository contains the backend server for the **R Jukebox** app (*formally the RaspberryPi Web Music Player*).

---
## 📀 Technologies used

* Express.js
* Puppeteer
* Socket.IO
* Axios

---
## 🚀 Running

* Use `yarn build` to to compile the Typescript code into the `build/` directory. 
* Use `yarn start` to start the Node.js server.
* Use `yarn dev` to simultaneously build and start the server.
